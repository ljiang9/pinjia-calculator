# 拼假计算器 pinjia-calculator

2026 年拼假神器：输入年假余额，算出全年每种拼法，按性价比排序——
**中秋 + 国庆「请3休13」「请6休17」，年度王炸！**

纯 Python 标准库，无第三方依赖，Python 3.10+。

## 玩法

```bash
python -m pinjia_calculator --annual 5        # 默认：王炸 spotlight + 性价比 Top5 + 最佳拼法月历
python -m pinjia_calculator --annual 10 --list # 列出年假足够覆盖的全部拼法（按性价比排序）
python -m pinjia_calculator --best            # 只看年度王炸（请3休13 / 请6休17）
```

输出示例（`--best`）：

```
[年度王炸·请3休13] 中秋后拼：请 3 天 → 休 13 天（09-25～10-07），性价比 3.33
[年度王炸·请6休17] 中秋后拼：请 6 天 → 休 17 天（09-25～10-11），性价比 1.83
```

拼法还会画成 ASCII 月历：`<>` = 烧年假的日子，`[]` = 白嫖的休息日。

彩蛋：

- `--annual 0` → 「你的拼假攻略：好好上班。」
- `--annual 20`（及以上）→ 「你可以直接退休了。」

## 拼法是怎么算出来的

程序内置 2026 年 7 个法定假期块和 6 个调休上班日。
对每个假期块，向"前拼"/"后拼"两个方向延伸：工作日烧 1 天年假，
周末和法定假免费；预算花完后继续穿过免费的日子，直到撞上下一个工作日。
性价比 = 多休天数 / 请假天数 =（连休天数 − 请假天数）/ 请假天数。

比如中秋（9/25–9/27）后拼 3 天：9/28、9/29、9/30 三个工作日烧年假，
一路穿过国庆 7 天假期，连休 9/25～10/7 共 13 天 → 请3休13。
再多烧 10/8、10/9、10/10（含调休上班的周六），连到 10/11 周日，
共 17 天 → 请6休17。

## 数据来源与核验记录

节假日安排依据国务院办公厅公布的 2026 年放假安排整理；
**每个起止日期的星期已于 2026-10-06 用 `date -d` 逐项核验**，结果如下：

| 假期 | 起止 | 星期核验 |
|---|---|---|
| 元旦 | 1/1–1/3 | 周四～周六；1/4（周日）上班 ✅ |
| 春节 | 2/15–2/23 | 周日～周一，共 9 天；2/14、2/28（周六）上班 ✅ |
| 清明 | 4/4–4/6 | 周六～周一 ✅ |
| 劳动节 | 5/1–5/5 | 周五～周二；5/9（周六）上班 ✅ |
| 端午 | 6/19–6/21 | 周五～周日 ✅ |
| 中秋 | 9/25–9/27 | 周五～周日 ✅ |
| 国庆 | 10/1–10/7 | 周四～周三；9/20（周日）、10/10（周六）上班 ✅ |

## 诚实局限

- 数据仅覆盖 **2026 年**，跨年拼法（如元旦前后连到 2025/2027）未计算。
- 未考虑你公司的实际排班、年假审批和调休差异，请假前请以 HR 为准。
- 单种拼法最多枚举 10 天年假；年假超过 20 天的，程序建议你直接退休。
- 娱乐 + 实用工具，不构成任何休假承诺。
